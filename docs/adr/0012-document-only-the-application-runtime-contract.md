# Document only the application runtime contract

Lens documentation covers the application build, published image, required
services, environment variables, database initialization/startup commands, and HTTP contracts.
It does not select a deployment environment or describe external infrastructure.
This keeps application requirements independent of an operator's environment
and avoids exposing information unrelated to the public project.

<summary>日本語</summary>

# アプリの実行契約だけを記録する

Lensの文書は、アプリのbuild・公開イメージ・必要なサービス・環境変数・
DB初期化と起動コマンド・HTTP契約を扱う。配置環境の選定や外部インフラの説明は含めない。
アプリ要件を運用者の環境から独立させ、公開プロジェクトに関係のない情報を露出させないためである。
