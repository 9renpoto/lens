# Preserve official original material for reprocessing

Historical decision: retain source material and acquisition provenance so searchable text can be regenerated without publisher access. The preservation decision is now recorded in [ADR 0004](0004-retain-earnings-pdfs-for-reprocessing.md), with storage and recovery in ADRs 0005–0006.

Existing discovery, identity and search behavior is documented as implementation reference, rather than release acceptance criteria, in [the pipeline reference](../reference/earnings-pipeline.md) and [search](../search.md). Remaining decisions are listed in [the task breakdown](../tasks/v0.2.md).

# 再処理のために公式の原本資料を保存する

過去の判断：原本と取得の出典情報を残し、公開元へアクセスせず検索用本文を再生成できるようにする。原本保持の判断は[ADR 0004](0004-retain-earnings-pdfs-for-reprocessing.md)、保存先と復旧はADR 0005〜0006へ引き継いだ。

既存の発見・識別・検索の挙動は、リリースの受入条件ではなく実装の参照情報として[処理基盤の説明](../reference/earnings-pipeline.md)と[検索](../search.md)に記載する。残る判断は[タスク分解](../tasks/v0.2.md)に記載する。
